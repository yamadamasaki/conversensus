# terminalText.test.ts — 端末に出す文字列から制御文字を落とす (#391)

## 何を

`forTerminal` が、CLI と常駐が端末に出す文字列から制御文字を落とすこと。

## なぜ

CLI と常駐は、File の本文 (他の参加者が書いたもの) や claude の出力を端末に出す。ESC で始まる端末の命令が
そのまま出ると、端末の表示を書き換えたり、題名や clipboard を操作されたりしうる。読む人の端末を、書いた人に
操作させない。

## どのように

- (例) 🔴 OSC (題名を変える `ESC ] 0 ; … BEL`) と CSI (画面を消す `ESC [ 2 J`) の ESC と BEL を落とす。改行とタブは残す
- (例) C1 の制御文字 (1 文字の CSI `0x9b`) と DEL も落とす
- (性質) 出力に落とすべき制御文字は無く、それ以外の文字は順に残る (落としすぎない)
  - **生成器**: 制御文字 (ESC・BEL・CSI・DEL・CR) と改行・タブ・ふつうの文字 (かな・括弧・絵文字) の小さなプールから
    引く。広い生成器では制御文字に当たらない
  - CR (`\r`) も落とす。行の頭に戻って、前に出た文字を上書きして見せられるため
