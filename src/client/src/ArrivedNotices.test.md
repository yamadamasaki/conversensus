# ArrivedNotices.test.tsx — module の知らせの欄のテスト仕様

## 何を

`ArrivedNotices` を検証する。画面右下に、module が受信から見つけた知らせ (届いた依頼など) を 1 つずつ出す欄である
(agent 段 4 R5・計画 Q3 案 A。module の口にしたのは計画 node-actions-request-module.md B1)。

## なぜ

依頼は誰かが答えを待っている。誰からの何の知らせかが一目で分かり、そこへ行けなければ、知らせは役に立たない。
欄の名前と見出しは module が持つ (core は依頼を知らない) ので、core が module の宣言どおりに描くことを確かめる。

## どのように

依頼に依らない試験用の module (「届いた問い」) を登録して、例で確かめる。

- 届いていなければ何も描かない
- module の欄の名前で欄を作る。見出しには module の文言に送り手のハンドル名を差し込み、本文は抜粋 (長ければ切って「…」)
- 登録されていない module の知らせは出さない (module を外した後に残ったものなど)
- 「開く」と × は、その知らせを受け口に渡す (開く道と既読は App が持つ)
