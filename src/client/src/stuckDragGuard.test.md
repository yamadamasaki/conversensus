# stuckDragGuard.test.ts — 終わらないドラッグの打ち切り

## 何をテストするか

「押していない移動 (`buttons=0`) が来たら合成 `mouseup` を投げてドラッグを打ち切る」
という判定そのもの。**投げる場合と投げない場合の両方**を固定する。

## なぜテストするか

これは**動きを止める方向の仕掛け**なので, 効きすぎると本物のドラッグが壊れる。
実測 (実 Safari + トラックパッド, 2026-08-13) では

- 押し込んだドラッグ: 押下 `buttons=1` / 移動 `buttons=1`
- タップ (暴走する): 押下 `buttons=0` / 移動 `buttons=0`

という差があり, **この差だけを根拠に**打ち切る。根拠が 1 つしかないので,
その 1 つを誤って広げていないことを検査で押さえる必要がある。

症状と原因の全体は `tests/paneDrag.spec.md` とモジュール冒頭のコメントにある。

## どのようにテストするか

- **打ち切る**: 押下 (`buttons=0`) の後の移動 (`buttons=0`) で `mouseup` が 1 回出る
- **打ち切らない (本物のドラッグ)**: 押下・移動とも `buttons=1` なら 0 回。
  ここが壊れると全てのドラッグが効かなくなるので, 最も重要な検査である
- **打ち切らない (ただの移動)**: 押下が無ければ 0 回。カーソルを動かしているだけの
  状態で `mouseup` を投げ続けないこと
- **1 回だけ**: 打ち切った後に動き続けても投げ直さない (自分が投げた `mouseup` を
  自分で拾って二重に投げないことの確認でもある)
- **正常な解放の後**: `mouseup` が来た後の移動では投げない
- **解除できる**: 戻り値を呼べば何もしなくなる

数え方は「window に来た `mouseup` の回数」— ハンドラが呼ばれたかではなく**結果**を見る。
