# template の版の通知の部品のテスト

## 何を

`TemplateNotices.tsx`。前に出ている File の Sheet に当てた template graph の、新しい版と削除の通知を画面右下に
出す部品 (計画 template-update.md D3)。

## なぜ

- **新しい版と削除で、できることが違う。**新しい版はその場で pull できる (「最新の版にする」)。削除は戻す版が
  無いので閉じるだけである。削除に pull の入口が出ると、押しても何も起きない
- 閉じるボタンは記号 (×) だけなので、**読み上げの名前にどの Sheet のどの template かを入れる**。通知が並んだ
  ときに、どれを閉じるのか分からなくなる
- 名前は消された template graph では読めないことがある (当てた版が読めないとき)。そのときも文が崩れないように
  する

## どのように

例で書く (部品は表示とボタンの配線だけなので、性質にする全称命題が無い)。

- 通知が無ければ何も描かない (右下の通知の並びに空の枠を出さない)
- 新しい版: 欄 (`role="status"`、名前「template の版」) に文が出て、「最新の版にする」で `onPull`、× (名前に
  Sheet と template を含む) で `onDismiss` がその通知で呼ばれる
- 削除: 文が出て、pull の入口は無い。名前を読めなければ「template」と出す

op-log から通知を求めて既読で落とす所は `notices/templateNotices.test.ts`、App を一周させる所は
`App.app-test.tsx` が見る。
