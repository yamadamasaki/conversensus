# readImportFile のテスト

## 何をテストするか

import で選ばれた `.conversensus` を読み、解釈した結果か、人に言う理由の文を返すこと。

- 最新形式のファイルが読めること
- JSON でないものは「ファイルの読み込みに失敗しました」になること
- JSON だが形が違うものは「ファイル形式が不正です:」に、どこが違うかの行を添えること

## なぜテストするか

左サイドバーの「import」と、File が 1 つも無いときの空の状態 (visual language §9.1) の
2 か所から使う。以前は Sidebar の中に書かれていたので、2 か所目を作るときに切り出した。
**失敗を黙らない**ことが要点で、理由の文が空になると、壊れているのか何も起きていないのかが
分からなくなる。

## どのようにテストするか

- ファイルは `Blob` で渡す (`File` は `Blob` なので、読む側の振る舞いは同じ)
- 旧版の移行は `parseConversensusFile` (shared) のテストが見ているので、ここでは
  最新形式だけを通す
