# UpdateNotice.test.tsx — 新しい版の知らせのテスト仕様

## 何を

`UpdateNotice` (新しい版が配られたことを知らせ、再読み込みを利用者に任せる) を検証する (#262)。

## なぜ

読み直すのは利用者が押したときだけ (利用者判断 2026-10-11)。書きかけの文字を消さないため。
押さずに閉じる口 (「あとで」) も要る — 古い版のままでも壊れないので、判断を強いない。

## どのように

- 知らせの領域 (`role="status"`) に「新しい版があります」を出す
- 「再読み込み」と「あとで」がそれぞれの口を呼ぶ
- 新しい版が無ければ何も描かない
