# StorageAtRiskBanner.test.tsx — 端末だけの File が消えるおそれの注意のテスト仕様

## 何を

`StorageAtRiskBanner` (保存領域が守られていない端末で、この端末だけの File が消されうることを知らせる) を
検証する (#263)。出すかどうかの判定のうち「守られていない」は `Sidebar` が `storagePersistence` から渡す。
ここでは件数と文言を見る。

## なぜ

アカウントに保存した File は消えても PDS から戻るが、**この端末だけの File (#253) は戻らない**。
消えてから気付いても遅いので、消える前に保存の口へ導く。ログインしていなければ、保存にはまずログインが要る。

## どのように

- 件数と「消すことがあります」を出す
- ログイン中は「アカウントに保存する」(File の詳細の口の名前)、未ログインなら「ログインして」を勧める
- 0 件なら何も出さない — 消えて困るものが無いのに注意しない
