# LocalOnlyBanner.test.tsx — 未ログインの編集の知らせのテスト仕様

## 何を

`LocalOnlyBanner` (未ログインの間に、この端末にだけある編集の件数を出し、押すとログインを始める) を検証する
(FPR 前 L-3)。

## なぜ

未ログインの編集は誰にも届かないのに、描いた側の画面には出ているので気づけない (FPR の確認 §1)。それまでの
「この端末にだけ保存」の表示 (`SyncStatusIndicator`) は、サイドバーがログイン中にしか描かないので**一度も出て
いなかった**。ログインすれば訊いてから送られる (L-1) ので、件数とログインへの入口で足りる。

## どのように

- 件数と「ログインすると送られます」を出す
- 押すとログインを始める
- **0 件なら何も出さない** — 未ログインで使うこと自体は普通のことなので、編集が無いのに知らせない
