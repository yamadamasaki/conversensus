# ClippedText のテスト

## 何をテストするか

`ClippedText` は省略で縮む文字で、切れているときだけ全体を自前の tooltip に出す (ヘッダの名前, 利用者の指摘
2026-10-12: ブラウザの tooltip (`title`) がボタンには出るのに名前には出なかった)。

- 切れていれば、少し待ってから全体を出し、離れたら消す
- 切れていなければ出さない
- 待っている間に離れたら出さない
- 中身 (File の名前を薄く、Sheet の名前を太く、など) を渡せば中身を描き、tooltip には全体の文字を出す

## なぜテストするか

切れていない名前に同じ文字を重ねて出すと邪魔になる。通り過ぎるだけのポインタで出ると、ヘッダの上を
動かすたびにちらつく。

## どのようにテストするか

happy-dom は配置をしないので、文字の幅 (`scrollWidth`) と箱の幅 (`clientWidth`) を差し替えて「切れている」を作る。
待ちは本物の時間で待つ (`CLIPPED_TOOLTIP_DELAY_MS` + 余裕)。tooltip は `document.body` に描くので `role="tooltip"` で引く。
