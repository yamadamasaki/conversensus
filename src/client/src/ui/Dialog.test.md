# Dialog のテスト

## 何をテストするか

覆い型のダイアログの共通の枠 `Dialog` と、ボタンの並び `DialogActions` (visual language §6)。

- **閉じ方が型で決まること** (§6.1)。確認は外側のクリックで閉じず、入力と知らせは閉じる。
  Esc はどの型でも閉じる。中身のクリックでは閉じない
- 知らせは `alertdialog`、ほかは `dialog` として読まれること。`title` が見出しになること
- `DialogActions` が破壊的な操作を左端に置き、残りを右に寄せること (§6.2)

## なぜテストするか

ダイアログの閉じ方は、以前は部品ごとに少しずつ違っていた (#275)。型ごとの決まりを
この枠 1 か所に寄せたので、ここが崩れると全部のダイアログが一度に崩れる。

確認の型が外側のクリックで閉じないのは、**重い操作の前の問いが、覆いを押しただけで
「キャンセル」に化けると、何に答えたのか分からなくなる** からである。逆に入力や知らせは
覆いを押して閉じられないと、閉じ方を探させることになる。

## どのようにテストするか

- 枠は覆いの子として描かれるので、`aria-label` で枠を引き、その親を覆いとして押す
- 型の違いだけが効く性質 (外側のクリック・Esc) は `test.each` で型ごとに回す
- 右に寄せることは、右側のまとまりの `margin-left: auto` で見る。happy-dom は配置を
  計算しないので、並びの順と寄せ方の指定を見るにとどめる
