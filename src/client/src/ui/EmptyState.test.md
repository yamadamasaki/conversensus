# EmptyState のテスト

## 何をテストするか

空の状態の部品 (visual language §9.1, #279)。

- 題が領域の名前 (`aria-label`) と見出しの両方になること
- 本文 (次に何をすればよいか) と操作の口が出ること
- アイコンが読み上げられないこと (飾りであり、意味は題が持つ)
- 本文や操作を渡さなければ、その枠を出さないこと

## なぜテストするか

空の状態は **何が無いか** と **次に何をすればよいか** を一緒に言うのが役目である。
題が読み上げで引けないと、支援技術では「何も無い画面」と区別が付かない。

## どのようにテストするか

部品だけを描いて、役割 (`region`・`heading`・`button`) で引く。実際の画面に置いた
ときの振る舞い (作ると開く、node ができると案内が消える) は App 結合
(`App.app-test.tsx` の「空の状態」) で見る。
