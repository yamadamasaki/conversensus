# GuideLink のテスト

## 何をテストするか

左サイドバーの下の、入門 (docs.conversensus.site) へのリンク (step4)。

- いまの言語の入門を指す (日本語は `/intro/`、英語は `/en/intro/`)。言語を切り替えると、文言と行き先が両方替わる
- 新しいタブで開き (`target="_blank"`)、`rel="noopener noreferrer"` を付ける
- 辞書のあるどの言語にも、入門の置き場所がある

## なぜテストするか

- 言語を切り替えても行き先が古いままだと、英語を選んだ人が日本語の入門に着く。文言だけ替わって
  行き先が替わらない食い違いは画面では気づきにくい
- 同じタブで開くと編集中の画面を離れる。`noreferrer` が無いと、この画面の URL (Deep Link には File の
  id が入る) が入門のサイトに渡る
- 言語を足したときに置き場所を書き忘れても、`Record<Locale, string>` の型で捕まる。3 つ目のテストは、
  置き場所が文書のサイトの外を指していないことを見る

## どのようにテストするか

部品だけを描き、`setLocale` で言語を替えて (`act` の中で、購読による描き直しを待つ) リンクの名前と
`href` を見る。テストの後は ja に戻す。
