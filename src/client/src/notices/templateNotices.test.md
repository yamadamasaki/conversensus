# template の版の通知のテスト

## 何を

`templateNotices.ts` の `templateNoticesOf` と、その既読の鍵 `templateNoticeKeyOf` (`noticeKeys.ts`)。当てた
template の版 (`appliedTemplateVersions` の結果) から、出す通知 (新しい版がある・template graph が削除された) を
求める (計画 template-update.md D3、K1・K5)。

## なぜ

- **既読の鍵は「どの端末でも同じ値」かつ「別の出来事には別の値」**でなければならない (ほかの通知と同じ、設計 F3)
- 新しい版の鍵に先端の版の指紋を入れるのは、**閉じた通知を、先端がさらに変わるまで出さない**ためである
  (計画 D3)。指紋を入れないと、一度閉じたら template graph をいくら直しても二度と出ない。逆に先端の切断面
  (File 全体の vector) を入れると、ほかの Sheet を編集するたびに閉じた通知がまた出る
- 削除は 1 度知らせれば足りるので、削除の印を入れて 1 つの鍵にする

## どのように

- **鍵の単射は性質で書く**: 「同じ鍵 ⇔ 当てた先・template graph・先端の版 (削除なら削除) が同じ」。当てた先と
  template graph は 3 つ、指紋は 2 つの小さなプールから引き、新しい版・最新・削除を混ぜる。同じ組を頻繁に引き、
  「指紋だけ違う」「削除と新しい版」の組に当たるようにするためである
- 例:
  - 新しい版と削除を版の並びのまま出し、最新のものは出さない。名前は読めたときだけ添える
  - 既読のものは出さない。先端が変われば (指紋が変われば)、閉じたものも出る
