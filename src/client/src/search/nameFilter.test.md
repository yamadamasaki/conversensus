# nameFilter.test.ts — 左サイドバーの名前の検索のテスト仕様

## 何を

`filterByName` (検索語で Folder・File・Sheet のツリーを絞る) と `findNameMatch` (名前の中の当たりの範囲) を
検証する (#249)。描き方は `Sidebar` が持ち、ここは何を残すかだけを決める。

## なぜ

結果は**ツリーをその場で絞って**見せる (利用者判断 2026-10-11)。絞り方を誤ると、次のどちらかが起きる。

- 当たっているのに消える。探したものが見つからない
- 当たっていないのに残る。絞った意味が無い

残す規則は次の 4 つで、どれも一覧の場所を失わないためのものである。

- 名前が当たった Folder は中身ごと
- 名前が当たった File
- Sheet の名前が当たった File (開いていない File も。一覧が Sheet の名前を持つ)
- それらを含む Folder

## どのように

- 例: 空の検索語は絞らない (null) / File・Sheet・Folder それぞれが当たったとき / 何も当たらない /
  Folder を使わない一覧
- 性質: **あらゆる名前と検索語で**、「名前か Sheet 名が当たる File は残る」と「残った File は
  自分が当たっているか、当たった Folder の中にある」が成り立つ
  - 生成器は 4 文字 (`a` `B` `c` 空白) から 4 文字までの名前を引く。**広い生成器では当たりがほとんど
    起きない**ので、小さなプールにして当たり・外れの両方を頻繁に引く。大文字の `B` と検索語の `b` で、
    大文字・小文字を区別しないことも引き当てる。空白は、検索語の前後の空白を無視することに当たる
  - File は奇数番目を Folder に入れ、偶数番目をトップ・レベルに置く。Folder の中と外の両方を毎回含める
