# NameHighlight.test.tsx — 名前の当たりの色付けのテスト仕様

## 何を

`NameHighlight` (名前の中の当たりを `<mark>` で囲む) を検証する (#249)。

## なぜ

色を付けても、**ボタンの名前 (読み上げ・テストが引く名前) は元の名前のまま**でなければならない。
`<mark>` の表示が inline でないと見なす環境 (happy-dom) では、名前の計算で前後に空白が入り、
「議事 録」という名前のボタンになった。`display: inline` を明示して直した。その退行をここで止める。

## どのように

- 当たった部分だけが `<mark>` に入り、ボタンの名前は「議事録」で引ける
- 当たらなければ `<mark>` を作らず、名前だけを出す
