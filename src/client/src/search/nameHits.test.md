# nameHits.test.ts — File をまたぐ検索の名前の当たりのテスト仕様

## 何を

`nameHits` (Folder・File・Sheet の名前の当たりを、開ける行の並びにする) を検証する (#248)。

## なぜ

ダイアログは結果を一覧で見せるので、行ごとに**開く先**が要る。Folder そのものには開く先が無いので、
当たった Folder の直下の File を行にする。当たりの規則はサイドバーの名前の検索 (`findNameMatch`) と
同じで、同じ検索語がサイドバーとダイアログで違うものを当てない。

## どのように

- File の当たりは、その File の最初の Sheet を開く
- Sheet の当たりは、その Sheet を開き、場所として File の名前を前に置く
- Folder の当たりは、直下の File ごとに 1 行。下位の Folder の名前も引く
- 空の検索語では何も出さない
