# GlobalSearchDialog.test.tsx — File をまたいで探すダイアログのテスト仕様

## 何を

`GlobalSearchDialog` (名前と中身を全 File から探し、1 件を押すと開く) を検証する (#248)。
中身を引く口 (`searchContent`) は差し替え、引いた検索語と返す結果をテストの中で決める。

## なぜ

- 名前は一覧に載っているので手元で引ける。**打つたびに出す**
- 中身は全 File を畳み込むので、**打ち終わってから 1 度だけ**引く。1 文字ごとに引くと Worker が詰まる
- 中身の検索は非同期なので、**古い検索語の結果が後から届く**ことがある。それを出すと、
  打っている語と違うものが並ぶ
- 上限で打ち切ったことを言わないと、無いものと誤解される

## どのように

- 開くと検索語の欄に focus がある (すぐ打てる)
- 名前の当たりがすぐ出て、押すと `onOpenName` が呼ばれる
- 「合」「合意」と続けて打つと、引くのは「合意」の 1 度だけ。結果に「File / Sheet」が出て、
  押すとその 1 件で `onOpenContent` が呼ばれる
- 打ち切った結果には「多すぎるので途中まで」と出る
- 「合意」の結果が「保留」の結果より後に届いても、「保留」の結果 (0 件) だけが出る
