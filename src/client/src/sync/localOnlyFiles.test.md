# localOnlyFiles のテスト

## 何をテストするか

「この端末だけの File」の印 (#253)。

- 印を付けた File だけがこの端末だけになる
- branch は元の File の印を写し、元の File (`trunk`) を覚える。印の無い File の branch には付けない
- 「この端末に残す」と答えたら、印の無い File (この変更より前に未ログインで作った File) にも付け、
  branch も `declined` にする
- 印を外すときは branch ごと外し、外した id を返す (呼び出し側がそれぞれ catch-up で送る)
- 壊れた値・保存領域が無いときは印が無いものとする
- 印が変わると、同じタブの聞き手に知らせる (サイドバーの印を描き直す)

## なぜテストするか

以前は「送らない」と答えても File の起源 (名前・最初の Sheet) がログインで送られ、ログインした後の
編集も送られた。印は「この端末から何も出さない」という約束そのものなので、印の付け外しが崩れると
答えに反して File が出ていく。

**branch の op-log は別の file id を持つ。**元の File だけに印を付けると branch の編集が出ていく。
外すときも branch を外し忘れると、保存した File の branch だけが永久に手元に残る。

## どのようにテストするか

保存領域は `Map` で作った `Storage` を渡す (localStorage を汚さない)。知らせは `window` の
イベントで聞く。
