# VersionTree のテスト

## 何をテストするか

version tree の描き方 (#73 T3)。

- branch の線は、その分岐の点の直下に字下げして出る (木として縦に並べる)
- change point の続きは「N 件の変更」に畳み、押すと広げる (Q2)
- 点を押すと、その点と、どの線の上か (`lane`) を選ぶ
- **選んだ点の直下に詳細 (inspector) を出す。出すのは 1 つだけ** (利用者の指摘 2026-10-12: 変更が多いと、木の下に
  出した inspector が押した点から遠くなって見えにくい)
- 見ている線の名前を太字にする (仕様: 現在いる trunk/branch を強調)

## なぜテストするか

仕様の図は線を横に並べるが、右サイドバーは狭いので縦の木にした。branch の線が分岐の点から離れると、
どこから分かれたのかが読めなくなる。選んだ点の `lane` は view graph のアドレス (branch か trunk か) になるので、
取り違えると別の線の姿を開く。

## どのようにテストするか

線を手で組んで描く (組み立ての正しさは `buildTimeline.test.md` が見る)。並びは描いた文字の位置で、
畳みは `aria-expanded` と広げた行の数で見る。
