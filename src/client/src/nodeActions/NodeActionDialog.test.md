# NodeActionDialog.test.tsx — 引数の dialog のテスト仕様

## 何を

引数の要る node の操作の dialog (`NodeActionDialog`、計画 node-actions-request-module.md N2・Q2 案 a) を検証する。

## なぜ

module は引数を**宣言**するだけで、dialog は core が描く。宣言の型 (`actors`・`choice`・`text`) ごとに
正しい入力が出て、選んだ値がそのまま操作に渡らなければ、module は意図した引数を受け取れない。
また「値は property に入っている」ので、dialog は**前に決めた値を初めから入れて**開く必要がある。

## どのように

3 つの型の引数を 1 つずつ持つ操作で、例で確かめる。

- 見出しは操作の名前。宣言の型ごとに入力が出て、初めの値 (`initial`) が入っている
- 選んだ・書いた値を「実行」で返す。`actors` は checkbox を何度押し直しても、最後に選ばれている人だけになる
- 必須の本文が空 (空白だけ) なら「実行」を押せない
- 実行できなかった理由 (dialog を開いている間に使えなくなったなど) は dialog の中に出し、閉じない
- 選ばれているのに参加者の一覧にいない人も出す。一覧がまだ届いていなくても、外せるようにするため
- キャンセルで閉じる
