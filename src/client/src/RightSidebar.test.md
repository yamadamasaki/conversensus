# RightSidebar のテスト

## 何をテストするか

右サイドバーの「property / timeline」の切り替え (#73 Q1)。

- 選んでいる方の中身だけを出す。timeline の中身は渡されたもの (`TimelinePanel`) をそのまま出す
- 押せば切り替えを頼む (state は App が持つ)

## なぜテストするか

右サイドバーは狭いので、2 つの pane を同時に出さずに切り替える (利用者の決定)。両方が出ると縦に長くなり、
一方が見えなくなる。

## どのようにテストするか

`RightSidebar` だけを描き、timeline の中身は目印の段落で代える。
