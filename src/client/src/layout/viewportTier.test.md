# viewportTier のテスト

## 何をテストするか

画面の幅の 3 段 (visual language §9.2, #278) と、段ごとのサイドバー・ヘッダの出し方。

- `tierOf`: 境目 (1024px・768px) は広い側に入る。幅について**単調**である
- `panelPresentation`: §9.2 の表のとおりに、並べる / 重ねる・開閉を覚えるか・外側で閉じるか
- `compactHeader`: 狭い段だけヘッダを記号だけにする

## なぜテストするか

段の判定と表は画面の外から見えにくい。iPad の縦や iPhone で開かないと食い違いに
気付かないので、表をそのまま例として固定する。

**開閉を覚えるのが広い段だけ**であることは、ここで固定しておきたい判断である。狭い段で
`localStorage` の「開いている」を復元すると、重ねて出すサイドバーがボディを覆ったまま
起動し、何も見えない画面から始まる。

## どのようにテストするか

- 境目は例で書く。境目の 1px 手前を必ず見る
- 単調性は全称命題なので性質で書く (`fast-check`)。幅は 0〜4000px の整数 —
  実機の幅はこの範囲に収まり、境目を何度も跨ぐ
- 表は 1 行ずつ例で書く。表そのものが仕様なので、性質にすると読みにくくなる
