# headerFold のテスト

## 何をテストするか

ヘッダの操作を「…」のメニューへ畳む段の決め方 (`headerFold.ts`, 利用者の指摘 2026-10-12)。

- 段 0 は何も畳まず、文字のボタンも文字を出す。段 1 で記号だけにして PNG を畳む (以前の「狭い画面」と同じ)
- 上限の段で `HEADER_FOLD_ORDER` のすべてを畳む。いつも使う操作 (undo・property・commit/merge) は順に入っていない
- 段を上げると、畳むものは増えるだけ
- 溢れていれば 1 つ上げ (上限で止まる)、溢れていなければ変えない

## なぜテストするか

段を上げて一度畳んだものが、次の段で戻ってくると、幅を詰めたのに広がる操作が出て、溢れと畳みを
繰り返す。溢れていないのに段を下げると、下げた段でまた溢れて上下に揺れる (下げるのは幅が変わったときに
下限からやり直すときだけ, `useFoldLevel`)。

## どのようにテストするか

- 例: 段 0・段 1・上限の中身
- **性質**: あらゆる 2 つの段で「低い段の畳み ⊆ 高い段の畳み」、あらゆる段と溢れの有無で次の段の規則。段は
  0 から上限までの全部を引く (数が少ないので全域が対象になる)
