# useFoldLevel のテスト

## 何をテストするか

`useFoldLevel` は箱の中身が溢れない段を求める (ヘッダの操作を畳む, `headerFold.ts`)。

- 溢れなくなる最初の段まで上げる
- 畳み切っても溢れるなら上限で止まる
- 中身 (名前など) が変わったら下限からやり直す
- 下限より下には下げない

## なぜテストするか

- 上げすぎると、入る操作まで「…」に隠れる
- 止まらないと描き直しが終わらない
- 中身が短くなったのに畳んだままだと、幅があるのに操作が隠れたままになる。幅が広がったときも同じ
  (幅の変化は ResizeObserver の知らせで、ここでは中身の変化で同じ道を通す)

## どのようにテストするか

happy-dom は配置をしないので、箱の `scrollWidth` を「段ごとに決めた中身の幅」に、`clientWidth` を決めた箱の
幅に差し替える。段ごとに 100 ずつ縮む中身 (段 0 で 600) を幅 350 の箱に入れると、段 3 (300) で収まる。
