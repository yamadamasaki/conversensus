# EdgeKindMenu のテスト

## 何を

`EdgeKindMenu` — 繋いだ両端から決まる edge の種類の候補が複数あるときに出すメニュー (step3 Phase 4 Q8)。

## なぜ

利用者が template graph を書くと、同じ組の node の間に複数の種類の edge が定義されうる。そのとき
仕様は「選択肢を提示する」。**選ばないことも許す** — 閉じたら種類無しの edge として繋ぐ。
接続そのもの (React Flow の取っ手を引く) は happy-dom では扱えないので、メニューの約束をここで固め、
接続から出るところは実機で見る。

## どのように

同じ組に 2 つの種類 (うち 1 つは label 無し) を持つ template と、別の template の種類を並べる。

- **候補を template ごとにまとめ、label の無い種類は「(名前なし)」と出す** (仕様: 種類は template ごとに
  まとまって表示されるとよい)。最後に「種類なしで繋ぐ」
- **選んだ種類を返す**
- **「種類なしで繋ぐ」と Escape は、種類無し (undefined) を返す**
