# SidePanel のテスト

## 何をテストするか

サイドバーの外枠の、並べる (`docked`) と重ねる (`overlay`) の出し方 (visual language §9.2, #278)。

- 並べるときは、ボディと同じ流れに置く (`position: relative`)
- 重ねるときは浮かせる (`position: absolute`)。畳んだ帯を並べて残すが、開いている間は
  帯の「広げる」ボタンを出さない — 同じ名前のボタンが 2 つ (一方は覆われて押せない) にならないように
- `onDismiss` を渡したときだけ外側に幕を敷き、押すと閉じる (狭い画面の左サイドバー)
- 畳んでいれば、重ねるときも帯と「広げる」ボタンだけ

## なぜテストするか

狭い画面ではサイドバーがボディを覆う。閉じる手段が見えない・押せないと、覆われた
ボディに戻れなくなる。どの段でどちらの出し方を使うかは `layout/viewportTier.test.ts` が見ており、
ここは出し方そのものを見る。

## どのようにテストするか

部品だけを描く。happy-dom は配置を計算しないので、`position` の指定と、ボタン・幕の有無で見る。
幕は飾りなので読み上げから外してあり (`aria-hidden`)、属性で引く。
