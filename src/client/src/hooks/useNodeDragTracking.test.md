# useNodeDragTracking.test.ts — ノードのドラッグを op に変える

step3 Phase 0 S0-2 で `GraphEditor` から切り出したフック。

## 何を

React Flow のドラッグの 3 つのコールバック (開始・途中・確定) が、正しい op と正しい画面の印を
出すこと。

## なぜ

移動先の解決と event の組み立ては `graph/dragStop.ts` で単体テスト済みだが、
**「開始時に控えた位置を確定時に使う」**と**「途中の印を確定で消す」**という配線は
`GraphEditor` の中にあってテストが無かった。

## どのように

- `getNodes` を差し替え可能な配列にし、ドラッグ中に React Flow が位置を書き換えるのを模す
- 印は `.react-flow__node[data-id]` の要素に付くので、その要素を body に置いて属性を見る

| テスト | 固定すること |
| --- | --- |
| 開始時の位置を from にして NODE_MOVED を流す | 控えた位置を使う (確定時の位置ではない) |
| 動いていなければ何も流さない | クリックだけのドラッグで op を積まない |
| グループの上に来たら入る先に印、確定で消す | 印の付け外し |
| 親の外へ出たら元の親に出る印 | 出る側の印 |
| 同じ親の中で動かしているだけなら印を付けない | |
