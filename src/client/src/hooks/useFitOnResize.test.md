# useFitOnResize のテスト

## 何をテストするか

キャンバスの大きさが変わったら表示をグラフ全体に合わせ直すフック (#257, visual language §8.5)。

- 観測を始めた直後の 1 回は合わせない (描き始めの位置は React Flow の `fitView` が決める)。
  その後の大きさの変化 (右サイドバーの開閉・窓の大きさ) で合わせる
- 利用者が表示を動かした後 (`onMoveStart` が event を伴って呼ばれた) は合わせ直さない
- プログラムからの移動では止めない。event が null のもの (検索で寄せる等) と、React Flow が
  表示の同期で渡す**素の object の印** (`{ sync: true }`) の両方。後者は実機で見つかった —
  描き始めの同期が人の操作に数えられ、右サイドバーを開いても合わせ直さなかった
- **合わせるのは 1 フレーム後**。React Flow も自分の ResizeObserver で大きさを測り直すので、
  同じ変化を先に受けてすぐ合わせると古い大きさで合わせてしまう (実機で発覚)
- 外したら観測をやめる

## なぜテストするか

File を開いた直後や右サイドバーを開閉した後に、node が端で切れていた (UI/UX review §2.4)。
一方で、利用者が自分で見ていた所から勝手に動かされるのも困る。**合わせる・合わせないの
境目**がこのフックの要点なので、そこを固定する。

## どのようにテストするか

happy-dom の `ResizeObserver` は大きさの変化を起こせないので、コールバックを手で呼べる
偽物に差し替える。合わせる操作は `fitView` の偽物の呼ばれた回数で見る。1 フレームは
`requestAnimationFrame` を 1 回待って進める。

実機の確かめで注意: **見えていないタブではフレームが回らず、ResizeObserver も呼ばれない**。
自動操作のタブで確かめるときは、スクリーンショットなどで描かせる必要がある。
