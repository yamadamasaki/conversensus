# messages のテスト

## 何をテストするか

すべての言語の辞書が、正の辞書 (ja) と**同じ形** (キーの道筋・文字列か関数か・関数の引数の数) を持つこと。
空の文言が無いこと (#50 i18n)。

## なぜテストするか

形の一致は型 (`Messages`) でも強制しているが、型は `as` などで黙らせられる。実行時にも比べておけば、
訳し忘れたキーで画面に `undefined` が出ることはない。空の文言は「とりあえず埋めた」訳し忘れの跡である。

## どのようにテストするか

辞書をたどってキーの道筋と値の種類 (`string` / `fn/引数の数`) の並びを作り、ja のものと比べる。
言語の一覧 (`LOCALES`) の全部を回すので、言語を足せば自動で対象になる。
