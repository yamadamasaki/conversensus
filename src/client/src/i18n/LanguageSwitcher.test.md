# LanguageSwitcher のテスト

## 何をテストするか

左サイドバーの言語の切り替え (#50 i18n, 計画 Q1)。

- 選ぶと言語が替わり、切り替え自身の文言 (「言語」→「Language」) もその言語で描き直す
- 言語の名前はそれぞれの言語で書く (「English」「日本語」)

## なぜテストするか

切り替えた後に画面が描き直されないと、選んだのに何も変わらないように見える。言語の名前をいまの言語で書くと、
いまの言語が読めない人は自分の言語を探せない。

## どのようにテストするか

部品だけを描いて選択を変える。テストの後は ja に戻す。
