# facingSides のテスト

## 何をテストするか

端の接続点を持たない edge に、向かい合う辺の中点を端として与える `facingAnchors` (#256)。

- 例: 右にある node へは右辺から左辺へ、上にある node へは上辺から下辺へ。
  横に並んだ 2 つの node の edge が上辺を回らないこと (Toulmin の上の段で起きた形)
- 性質: どんな 2 つの矩形でも、端はそれぞれの node の辺の上にあり、両端の辺は向かい合う
- 性質: 向きを逆にすると、同じ 2 辺を入れ替えて使う

## なぜテストするか

node の接続点は 4 辺にあるが、接続点を持たない edge は React Flow が最初の接続点 (上辺) を
両端に使う。template graph の種から作った edge は接続点を持たないので、横に並んだ node の
edge が上辺の外を回り、label が重なって読めなかった (#256)。

「辺の上にある」「向かい合う」は、**あらゆる配置で**成り立ってほしい命題なので性質で書く。
例だけでは、node の大きさが違うときや斜めに離れているときを引けない。

## どのようにテストするか

- 生成器: 位置は ±2000、大きさは 20〜400 の整数の矩形。node の大きさが揃わない場合と、
  重なっている場合 (中心が近い) も引けるように、位置と大きさを独立に引く
- 逆向きの性質では、横と縦の差がちょうど同じ (斜め 45°) の配置を除く。どちらの軸を
  選んでもよい境目で、逆向きの選び方が揃う保証は要らない
