# grouping.test.ts — テスト仕様

## 何をテストするか

`grouping.ts` の 2 つのイベント組み立て関数 —
`buildNodesGroupedEvent` (グループ化) と `buildNodesUngroupedEvent` (解除) — を
純関数として検証する。

## なぜテストするか

グループ化 / 解除の難しさは**座標系の変換**にある。子ノードの `position` は親からの
相対座標なので、グループへ入れる / 出すたびに基準が変わる。ここを間違えると
「グループを解除したら中身が別の場所に飛ぶ」(ANA-111) という壊れ方をする。

React のフックの中に置くとこの計算を単体で試せないため、S3 で
`useGroupNodes` から純関数として切り出した。フック側は
「選択を集めて dispatch する」だけの配線に留めてある。

## どのようにテストするか

### ヘルパ

`node(id, position, parentId?, extra?)` は既定で `measured` = 100×50 のノードを作る。
外接矩形の計算にサイズが効くため、既定値まかせにせず明示している。
`groupNode(...)` は `type` を `groupNode` にし、`style` と `measured` に同じ寸法を入れる。

### 観点ごとの意図

- **`buildNodesGroupedEvent`**
  - 選択が空なら `undefined`。呼び出し側 (フック / ボタン) が何もしないで済むように。
  - **layout**: 外接矩形に `GROUP_PADDING` と `GROUP_TITLE_HEIGHT` を足した値になること。
    題材は (100,100)-(400,250) で、期待値 (80,50,340,220) は手計算できる。
  - **`outerPosition` / `innerPosition` の使い分け**: 前者は「グループの外に居るときの
    位置」= 現在の `position`、後者は「グループの子としての位置」= グループの左上からの
    相対座標。この 2 つを取り違えると、グループ化した瞬間に中身が飛ぶ。
  - **選択ノードの親が揃っているとき**: 新しいグループ自身もその親の子になり、
    グループの `position` は親からの相対座標になる (絶対座標のまま入れると入れ子で飛ぶ)。
  - **親が揃っていないとき**: グループはトップレベルに作る。どちらか一方の親を
    選ぶ根拠がないため。

- **`buildNodesUngroupedEvent`**
  - グループ以外を渡すと `undefined`。delete と違い、解除はグループにしか意味がない。
  - **トップレベルのグループ**: 子は絶対座標でトップレベルへ出る。
  - **グループを動かした後の解除**: 設計の受入基準そのもの。`outerPosition` が
    `absolutePositionOf(child)` と一致することを見る。
    ペイロードを**解除時点の実状態**から作っているから成立する。グループ化時点の
    値を使い回す実装 (= `invertEvent(NODES_GROUPED)` がしていること) では、
    グループを (500,500) へ動かした分だけ子がずれる。
  - **入れ子のグループ**: 子は一段上のグループへ移り、`outerPosition` はその
    グループから見た相対座標になる。トップレベルと同じ扱いにすると飛ぶ。
  - **`alsoUngrouped`**: 入れ子のグループをまとめて選んで解除したとき、消える予定の
    グループを親に指定してしまうと孤児が生まれる。生き残る一番近い祖先まで遡ることを
    固定する。フックは全イベントを 1 つのスナップショットから組み立てるため
    (`dispatch` の結果は `getNodes()` に即座には反映されない)、この引数が必要になる。
  - **子を持たないグループ**: `children` が空のイベントを返す (グループだけが消える)。

- **往復テスト**: グループ化 → `applyEvent` → 解除 → `applyEvent` で、
  ノードの `parentId` と `position` が元通りになること。
  組み立て側 (`grouping.ts`) と適用側 (`applyEvent.ts`) の取り決めが噛み合って
  いないと通らないため、両者の結合を 1 本で守れる。
