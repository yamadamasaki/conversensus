# seedLocale.test.ts — 作り込みの種の言語のテスト仕様

## 何を

`localizeSeed` (作り込みの template graph の種を、利用者の言語の種類名にする) を検証する (#330 案 B)。

## なぜ

作り込みの種 (Toulmin model) は誰の言語でもないので、「Toulmin model を追加」したときに利用者の言語で File へ
焼き込む。以前は en の利用者にも「主張」「データ」が出ていた。焼き込んだ後はふつうの利用者のデータで、
利用者が作った template と同じく必要な人が訳す。

## どのように

- **en では種類名が英語になる** (node と edge の例を 1 つずつ)
- **種の表の言語 (ja) と訳の無い言語では表のまま** (同じ object を返す)
- すべての種について:
  - **訳しても id と端 (from / to) は変わらず、template の形のまま。**種類の照合 (`TemplateSchema`) と
    並べ方 (`KindPlacement`) は id で引くので、訳が id を変えると並べ方が崩れる
  - **en ではすべての種類名と説明が訳されている。**日本語の字 (かな・漢字) が残っていないことで見る。
    種を足したときの訳し漏れを捕まえるため、例ではなく全部の種・全部の種類を回す
