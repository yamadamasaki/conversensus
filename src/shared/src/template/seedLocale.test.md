# seedLocale.test.ts — 作り込みの種の言語のテスト仕様

## 何を

- `localizeSeed` (作り込みの template graph の種を、利用者の言語の種類名にする) (#330 案 B)
- `multilingualSeed` (それに加えて、種が持つすべての言語の名前・説明を付ける) (#356)

## なぜ

作り込みの種 (Toulmin model) は誰の言語でもないので、「Toulmin model を追加」したときに利用者の言語で File へ
焼き込む。以前は en の利用者にも「主張」「データ」が出ていた。

#356 で、焼き込むのは複製する人の言語だけではなくなった。種が持つすべての言語の名前・説明を template graph に
入れ、見る人の言語で表示する (`kindLocale.ts`)。**入れ漏れると、複製した人と違う言語の参加者には、その言語の
訳があるのに template graph の名前が出る。**

## どのように

- **en では種類名が英語になる** (node と edge の例を 1 つずつ)
- **種の表の言語 (ja) と訳の無い言語では表のまま** (同じ object を返す)
- すべての種について:
  - **訳しても id と端 (from / to) は変わらず、template の形のまま。**種類の照合 (`TemplateSchema`) と
    並べ方 (`KindPlacement`) は id で引くので、訳が id を変えると並べ方が崩れる
  - **en ではすべての種類名と説明が訳されている。**日本語の字 (かな・漢字) が残っていないことで見る。
    種を足したときの訳し漏れを捕まえるため、例ではなく全部の種・全部の種類を回す

### multilingualSeed (#356)

- Toulmin を en で複製すると、名前は英語、`labels` は表の言語 (ja) と en の両方、説明も両方を持つ。edge の種類も同じ
- label の無い edge の種類は、表の言語の名前を持たない (空の名前を訳として持たない)
- すべての種について、**template graph に複製して読み替えると**、ja と en の参加者がそれぞれ自分の言語の名前を
  引ける。`templateGraphOf`・`templateFromSheet` を通すので、property への書き出しと読み戻しまで含めて見る

変異で確かめた: 表の言語を集める所を外すと 2 つが、説明を付ける所を外すと 1 つが落ちる。
