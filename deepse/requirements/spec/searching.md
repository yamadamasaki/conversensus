# searching

グラフ内の文字列を検索することができる.

## 検索対象

- 範囲: 自分の projection
  - 他の参加者が書いた要素も, 同期して自分の projection に入っていれば検索の対象になる
  - 他人のリポジトリを直接見に行くことはしない
  - 遠い将来に他人のリポジトリも対象としたくなったら, その時には indexer のようなものを用意することになるだろう
- グラフ: 現在表示している sheet, あるいは branch
  - step 2 では op-log ではない. つまり時間を遡らない. 何らかのタイムラインを見る仕組みは欲しい (→ step 3)
  - 複数のグラフを串刺しにしたくなるかもしれない. 例えば file (s) (→ step 3)
- 要素:
  - node/edge の label
  - markdown ノードのような文字列を持つノードの content
  - property の値 (文字列に変換して)

## 検索方法

検索の仕方は, 下記のような常識的なものとする

- 文字列の部分一致
- 大小文字を無視するか否か
- 文字列の完全一致 (単語検索) はとりあえずなくても良い (→ step 3?)
- 正規表現による検索はとりあえずなくても良い (→ step 3?)
- Graph Query Language (→ step 3?)

## UI

例えば,

- 画面右上に検索窓, あるいは検索ボタンで検索窓がポップアップ
- 検索窓には
  - テキスト入力フィールド
  - 大小文字比較のトグル
  - enter
- 検索結果の一覧ダイアログ
  - 要素の種類 (node/edge, label/content/property)
  - content の場合は, 前後のテキストも部分的に表示
  - property の場合は, 名前, 型も表示
  - ダブル・クリックにより, グラフ内で対象をハイライト表示
    - property がヒットした場合は, その node/edge の property のどれかが対象になっていることがわかればよい. アイコン表示程度でもよい (property editor まで開くかは未決)
  - ダイアログは移動可能
  - close ボタンにより閉じる
