## 0. 要約

**template の新しい機能 (版の知らせ・最新の版にする・外す・違反の印・property の型) は、既存の骨格の中に収まっている。**
知らせは右下の通知の箱に積まれ、版を進める・外すは Sheet の「…」に、型と編集の可否は property の欄に入った。
新しい場所は作っていない。

気になるのは次の 3 つ。

1. 🟠 **当てた先の property の欄で、宣言した型が出ず「文字列」と出る** (§2.3)。型を宣言した利用者から見ると、
   宣言が効いていないように見える
2. 🟡 **template graph の property の欄で、型の入力欄が狭い**。例 (placeholder) が切れ、英語では書いた型そのものも切れる (§2.3・§3)
3. 🟡 **template の版の知らせに件数の上限が無い** (§2.1)。届いた知らせ (#393) は File ごとに畳むが、こちらは畳まない

前回の 🟠「node の本文が切れる」(v1.4.0 §2.3) は続いている。Toulmin の template graph でも「論証が示そうとしている結論」の
2 行目が切れる。

## 2. 所見

**重さ**: 🟠 分かりにくい / 🟡 不揃い / 🟢 良い

### 2.1 template の版の知らせ (D3)

- 🟢 右下の通知の箱に、競合の知らせ・届いた知らせと一緒に積まれ、重ならない。「最新の版にする」がその場で押せる
- 🟡 **件数の上限が無い。** 当てた template が多い File で template graph をまとめて書き換えると、右下に積み上がる。
  届いた知らせ (#393) と同じく、File ごとに数件で畳んで「ほか N 件」にするとよい

### 2.2 Sheet の「…」(D2・D6)

- 🟢 「…を最新の版にする」は新しい版があるときだけ、「…を外す」は後から当てたものだけに出る。押せない口を出さない
- (英語の画面の折り返しは §3)

### 2.3 property の欄 (T5・T7)

- 🟠 **当てた先で、宣言した型が出ない。** 型の列は値の型ではなく宣言の型を出すべきだが、template が配った property も
  「文字列」と出る (撮影の「章」は `number?`、「確かさ」は `'高' | '中' | '低'` を宣言している)。行の型 (`row.type`) が
  `string` のままで、宣言は別の欄 (`declaredType`) にあるため。**宣言があればそれを出す**のが筋
- 🟡 **template graph の欄で、型の入力欄の例が切れる** (「型 (例: number・'高'」まで)。欄が狭い。例を短くするか、
  欄の下に出す
- 🟢 固定の値は「template が値を決めていて、変更できません」と出て、入力欄にならない。選択肢の型は select になる

### 2.4 graph と node

- 🟢 種類のメニューは見た目ごとに字下げで並び、group の種類が group の下に出る (#406・#412)
- 🟢 違反の edge は破線と色の両方で示し、hover で理由が出る。消されずに残る
- 🟢 template graph の地が薄い紫になり、当てた先と取り違えにくい (#404)
- 🟢 graph node を選ぶと「名前を変える」が出る (#402)。ダブルクリックで開くことと両立している
- 🟠 (前回の続き) node の本文が 2 行目で切れる。Toulmin の template graph の種類の説明が読めない

## 3. 英語の画面

- 🟡 **template graph の property の欄で、型の入力欄が値そのものも切る。** 英語の例の `'high' | 'mid' | 'low'` は
  `'high' | 'mid'` までしか見えない (日本語の `'高' | '中' | '低'` は収まる)。例 (placeholder) だけでなく、書いた型が
  読めない。§2.3 の U2 は「例を短くする」ではなく**型の入力欄を広げる** (「適用先で編集できる」を下の行に回す等) のが筋
- 🟢 Sheet の「…」の `Detach "Argument notes"` は 1 行に収まる。`Update "<name>" to the latest version` は長い名前で
  2 行に折れうるが、ボタンの中で折れるだけで崩れない
- 🟢 右下の知らせ (`"Argument notes" applied to "Reading notes" has a newer version`) は 3 行に折れるが、
  「Update to latest」のボタンと × は横に並んだまま
