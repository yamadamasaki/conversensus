# visual language — 見た目の体系

> [design language](./design-language.md) の続き。design language が **どこに何を置くか** を決めるのに対し、
> この文書は **どう見せるか** (色・文字・余白・アイコン・状態・ダイアログ・言葉・グラフの描き方) を決める。
> 出所: [UI/UX review v1.0.0 §3](../../reports/ui-ux-review-v1.0.0.md)、issue #266 (C1)。
> 利用者の決定 (2026-10-09): アイコンは Lucide、概念語は英語のまま、ダークモードは変数の口だけ用意する。

## 0. なぜ要るか

v1.0.0 では部品ごとに見た目を決めていたので、**色のリテラルが 46 種類、角丸が 6 種類、文字の大きさが 8 種類**に
散っていた。しかも同じ色が別の意味を兼ねている。

- 青 (`#4f6ef7`) が「主の操作」「選択」「リンク」「ラベル」「commit」を兼ねる
- 橙 (`#f97316`) が「差分の変更」「merge ボタン」「group へ入れる先」を兼ねる
- 白地の文字・アイコンの多くが WCAG AA に届かない (⚙ 1.67、`#4f6ef7` 地の白文字 4.28)

この文書の決まりは **役割 → 値** の順に書く。部品は値ではなく役割 (CSS 変数) を参照する (#267)。

### 下限 (どの決まりよりも先に守る)

- **コントラスト**: 文字 4.5:1 以上、アイコン・線・枠などの意味を持つ図形 3:1 以上 (WCAG AA)。無効の表示は除く
- **hover に頼らない**: iOS には hover が無い。hover でしか出ない説明・操作を、唯一の手段にしない
- **キーボード**: すべての操作がキーボードで届き、フォーカスが見える (§5)

## 1. 色の役割

CSS 変数は `--cs-` を前置して `:root` に置く (`index.css`)。**ダークモードは値を足せる形だけ用意し、今回はライトの値だけを決める。**

### 1.1 地と線と文字 (中立)

| 役割 | 変数 | 値 | 用途 |
| --- | --- | --- | --- |
| 地 | `--cs-bg` | `#ffffff` | ボディ・ダイアログ・node |
| 地 (控えめ) | `--cs-bg-subtle` | `#f5f5f5` | サイドバー・ヘッダ・帯 |
| 地 (hover) | `--cs-bg-hover` | `#ebebeb` | 行・ボタンの hover |
| 線 | `--cs-border` | `#d4d4d4` | 入力欄・node・区切り (`#ccc` `#ddd` をまとめる) |
| 線 (控えめ) | `--cs-border-subtle` | `#ebebeb` | 面の中の区切り (`#eee` `#f0f0f0`) |
| 文字 | `--cs-text` | `#213547` | 本文 (12.6:1) |
| 文字 (補足) | `--cs-text-muted` | `#666666` | 補足・空の状態・アイコン (白地 5.7:1、`--cs-bg-subtle` 地 5.3:1) |
| 文字 (無効) | `--cs-text-disabled` | `#a3a3a3` | 無効の文字・アイコン (コントラストの下限の対象外) |

> `#999` `#aaa` `#888` `#777` は補足の文字に使われていたが、白地で 2.3〜4.5:1 に留まり AA に届かない。
> 補足はすべて `--cs-text-muted` に寄せ、より薄くしたいものは「無効」か「要らない文字」かを見直す。

### 1.2 アクセント (主の操作・選択・フォーカス)

| 役割 | 変数 | 値 | 用途 |
| --- | --- | --- | --- |
| 主の操作 | `--cs-primary` | `#3a5bd9` | 主のボタンの地 (白文字 5.7:1)・リンク・主の操作の文字 |
| 主の操作 (hover) | `--cs-primary-hover` | `#2f4bb8` | |
| 選択 | `--cs-selection` | `#3a5bd9` | 選ばれた node・edge・行の枠 |
| 選択の地 | `--cs-selection-bg` | `#eef2ff` | 選ばれた行・開いているタブ |
| フォーカス | `--cs-focus` | `#3a5bd9` | `:focus-visible` の輪 (2px) |

- **主の色は 1 つの画面の 1 つの面につき 1 個だけ**。ダイアログの「OK」、merger の「merge」など。
  「グループ化」「PNG」のような副の操作は主の色を使わない (§5)
- 選択と主の操作は同じ色相を使う (macOS のアクセント色と同じ考え)。ただし変数は分けておき、別の色にしたくなったら値だけを変える
- `#4f6ef7` は白文字に対して 4.28:1 で AA に届かないので、`#3a5bd9` に寄せる

### 1.3 差分と競合 (グラフの言語)

**ここはグラフの言語の一部** (merger・branch の表示・conflict list) で、ほかの用途に使わない。

| 役割 | 変数 (線 / 地 / 文字) | 値 | 描き方 (§8) |
| --- | --- | --- | --- |
| 追加 | `--cs-diff-add` / `-bg` / `-text` | `#16a34a` / `#f0fdf4` / `#15803d` | 実線の枠 2px |
| 変更 | `--cs-diff-update` / `-bg` / `-text` | `#ea580c` / `#fff7ed` / `#c2410c` | 実線の枠 2px |
| 削除 | `--cs-diff-delete` | `#a3a3a3` | ghost (半透明・破線・打ち消し線) |
| 競合 | `--cs-conflict` / `-bg` / `-text` | `#dc2626` / `#fef2f2` / `#b91c1c` | **破線**の枠 2px |

- 線の値は白地で 3:1 以上 (追加 3.3、変更 3.6、競合 4.8)。文字に使うときは `-text` (4.5:1 以上) を使う
- **色だけで区別しない**: 追加と変更は色だけが違うので、node の隅に記号 (§8.4) を添える。競合は破線、削除は打ち消し線で、形でも区別する
- 今の橙の兼用をほどく: merge のボタンは主の色 (§1.2)、group へ入れる先の印は選択の色 (§8.3) にする

### 1.4 状態の知らせ

| 役割 | 変数 (線 / 地 / 文字) | 値 | 用途 |
| --- | --- | --- | --- |
| 破壊的 | `--cs-danger` / `-bg` / `-text` | `#dc2626` / `#fef2f2` / `#b91c1c` | 削除のボタン・取り消せない操作・入力の誤り |
| 警告 | `--cs-warning` / `-bg` / `-text` | `#d97706` / `#fffbeb` / `#b45309` | 未ログインの帯・未同期・共有が切れた |
| 成功 | `--cs-success-text` | `#15803d` | 「同期済み」など (地は使わない) |

- 破壊的と競合は同じ赤を使う。どちらも「失うかもしれない・判断が要る」を意味する。部品の形 (ボタンか、グラフの破線か) が違うので混ざらない
- 警告 (琥珀) と差分の変更 (橙) は色相が近い。前者は帯・文字、後者はグラフの枠にしか使わないので並ばない

### 1.5 種類の色 (template)

template が決める種類 (label) の色は、**今は決めない**。label の chip は中立 (`--cs-bg-subtle` 地・`--cs-text-muted` 文字) で描く。
template が種類に色を持てるようにするとき (D6) は、§1.3・§1.4 と取り違えない淡い 8 色を別に定める。

## 2. 文字の段

| 段 | 大きさ / 行の高さ | 太さ | 用途 |
| --- | --- | --- | --- |
| 補足 | 11px / 1.4 | 400 | chip・バッジ・edge の label・注記・時刻 |
| 本文 | 13px / 1.5 | 400 | サイドバー・ヘッダ・ダイアログ・右サイドバー・入力欄 |
| 見出し | 15px / 1.4 | 600 | ダイアログの題・pane の見出し |
| 題 | 18px / 1.3 | 600 | 空の状態の見出し |

- **11px より小さくしない。**今の 9・10px (branch の行・label の chip) は 11px に上げる
- 本文は 13px にそろえる (今は 11〜14px が混ざる)。File の行と Sheet の行の差は、大きさではなく太さ (File 600) と字下げで付ける
- **node の文字** (#173): node の本文は 13px (UI の本文と同じ段)。node の中の markdown の見出しは h1 15px・h2 14px・h3 以降 13px の太字にとどめ、node から溢れる大きさにしない。見え方の大小はキャンバスの zoom に任せる
- フォントは `system-ui, -apple-system, "Hiragino Sans", "Noto Sans JP", sans-serif` の 1 系統。Arial は外す
- **monospace は機械の値にだけ使う**: id・hash・DID・参加コード。branch の名前は人が付ける名前なので monospace にしない

## 3. 余白・角丸・影

- **余白は 4px 刻み**: 4・8・12・16・24 (`--cs-space-1`〜`--cs-space-6`、20 は使わない)
- **角丸は 2 種類**: 小部品 (ボタン・入力欄・chip・タブ) 4px (`--cs-radius-sm`)、面 (node・ダイアログ・ポップオーバー・通知) 8px (`--cs-radius-md`)。
  丸 (50%) は接続点とアバターだけ
- **影は 2 段**: 浮いた面 (ポップオーバー・メニュー・通知) `0 2px 8px rgba(0,0,0,.15)`、ダイアログ `0 8px 24px rgba(0,0,0,.2)` と背景の幕 `rgba(0,0,0,.4)`

## 4. アイコン

- **Lucide (`lucide-react`) にそろえる。**絵文字・記号の文字 (`⚙` `📁` `⌘` `⧉` `✕` `↑`) をアイコンに使わない
- 大きさは 16px (行の中は 14px)、線の太さは 1.75、色は `currentColor` (文字の色を継ぐ)
- **アイコンだけのボタンは**、`aria-label` と tooltip を必ず持つ。そのうえで、**tooltip が無くても意味が分かるものに限る**
  (閉じる・検索・設定・undo / redo・展開)。そうでないもの (import・参加・metagraph など) には文字のラベルを添える。iOS では tooltip が出ないため
- tooltip はキーボードのフォーカスでも出す

### 4.1 対応表

| 今 | 意味 | Lucide |
| --- | --- | --- |
| `+` (左上) | File を作る | `FilePlus` + 文字 |
| `↑` (左上) | import | `FileUp` + 文字 |
| `📁` (左上) | Folder を作る | `FolderPlus` |
| 参加 | 参加コードで参加する | `UserPlus` + 文字 |
| `📁` (File の行) | Folder へ移す | `FolderInput` |
| `⚙` | File・Sheet の詳細 | `Ellipsis` (詳細は設定ではないので歯車にしない) |
| `⌘` | metagraph (#270) | `Network` |
| `▼` `▶` `◀` | 開閉 | `ChevronDown` / `ChevronRight` / `PanelRightClose` |
| `✕` | 閉じる | `X` |
| branch の `✕` (削除) | branch を削除 | `Trash2` (閉じると削除を同じ記号にしない) |
| branch の `↑` | trunk に merge | `GitMerge` |
| `🔍` | Sheet 内検索 | `Search` |
| `🏷` | property editor の開閉 | `PanelRight` |
| Undo / Redo | | `Undo2` / `Redo2` |
| グループ化 / 解除 | | `Group` / `Ungroup` + 文字 |

## 5. 操作の状態

| 状態 | 見え方 |
| --- | --- |
| 普通 | 主: `--cs-primary` の地に白文字。副: 地なし・`--cs-text`、枠 `--cs-border`。記号: 地なし・`--cs-text-muted` |
| hover | 主: `--cs-primary-hover`。副・記号: `--cs-bg-hover` の地 |
| 押下 | hover より 1 段暗い地 |
| 選択 (トグルが on) | `--cs-selection-bg` の地 + `--cs-primary` の文字 |
| フォーカス | `:focus-visible` で `--cs-focus` の 2px の輪 (外側 2px) |
| 無効 | `--cs-text-disabled` の文字・アイコン、地も枠も付けない、`cursor: not-allowed`、`disabled` 属性 |
| 実行中 | ボタンの文字を進行の言葉に替え (「同期中…」)、無効にする |

- **ボタンは主・副・記号の 3 種類だけ**。ヘッダは副と記号だけで組み、主の色を使わない
- **使えない操作は無効にして見せる** (#269): 何も選んでいないときの「グループ化」、group を選んでいないときの「グループ解除」など。
  隠すと置き場所が変わってしまうので、隠さずに無効にする
- 破壊的なボタンは `--cs-danger` の枠と文字 (地なし)。確かめのダイアログの中でだけ `--cs-danger` の地にする

## 6. ダイアログと通知の型

### 6.1 5 つの型

| 型 | 使う場面 | 閉じ方 | 例 |
| --- | --- | --- | --- |
| 確認 | 取り消せない・重い操作の前 | Esc・「キャンセル」(外側のクリックでは閉じない) | File の削除、ログアウトでの消去 |
| 入力 | 名前など 1〜数個の値を受け取る | Esc・外側のクリック・「キャンセル」 | Folder を作る、参加コード |
| 知らせ | 結果を伝えるだけ | Esc・Enter・「OK」 | import の失敗 |
| ポップオーバー | 要素の詳細を見る・直す | Esc・外側のクリック・「OK」 | File・Sheet の詳細 (`SettingsPopup`) |
| 通知 | 背後で起きたことを伝える | 自分で閉じる (重要度による、§6.3) | 競合・上書き・fork・未ログインの帯 |

- 部品は型ごとに 1 つ (#275)。今の `ConfirmDialog`・`InputDialog`・`AlertDialog`・`SettingsPopup` と参加者のダイアログを、この 5 つの型に寄せる

### 6.2 ボタンの並びと言葉

- **右下に並べ、主を右端に置く** (macOS の並び)。「キャンセル」は主の左
- **破壊的な操作は主から離す**: 左端に置く。ポップオーバーでは「OK」から最も離す (#271)
- 主のボタンの言葉は **動詞で、何が起きるかを書く** (「削除」「merge」「参加」)。ただし、ポップオーバーで直したものを確定するときだけ「OK」を使う
  (design language の「保存 → OK」)。local first なので、利用者から見て「保存」という別の手順は無い
- 確認の文には、**何が失われるか**と**取り消せるか**を書く

### 6.3 通知の重要度

| 重要度 | 見え方 | 閉じ方 | 例 |
| --- | --- | --- | --- |
| 判断が要る | `--cs-conflict` の左の帯 + 操作のボタン | 判断するか、自分で閉じるまで残る | 競合を検出した、相手が保留した競合が届いた |
| 知らせ | `--cs-border` の枠 | 自分で閉じる | 別の版で上書きされた |
| 状態 | 画面の上の帯 (`--cs-warning-bg`) | 状態が解けると消える | 未ログイン、共有が切れた |
| 進行 | 左サイドバー下の文字 | 自動 | 同期中… |

## 7. 言葉の表 (glossary)

**方針: conversensus の概念を指す語は英語のまま使い、操作・説明は日本語で書く。**設計文書と同じ語を画面に出すので、
i18n (#50) で訳がぶれない。英語の語は文の中で前後に半角の空白を置く (「File を削除」)。

| 語 (画面に出す形) | 使わない形 | 意味 |
| --- | --- | --- |
| File | ファイル | graph container。参加者を持つ単位 |
| Sheet | シート | File の中の 1 つのグラフ |
| Folder | フォルダ | File を整理する手元の入れ物 |
| trunk / branch | ブランチ | Sheet の本流と分岐 |
| commit | コミット | branch の変更を 1 つにまとめて記録する |
| merge | マージ | branch を trunk に取り込む |
| fork | フォーク | 競合を保留し、自分の側を別に残す |
| template / template graph | テンプレート | 種類と形を決めるグラフ |
| metagraph | メタグラフ・index | Sheet を node にした File の見取り図 |
| node / edge | ノード・エッジ | グラフの要素 |
| label | | node・edge の種類の名前 (「ラベル」は使わない) |
| property | | node・edge の名前の付いた値 (今の「プロパティ」から替える) |
| group | グループ | node をまとめる枠 (「グループ化」→「group にまとめる」) |
| 競合 | コンフリクト | 二人の編集がぶつかったもの |
| 参加者 | メンバー | File を共有している人 |
| アカウント | | ログインしている ATProto のアカウント |
| **アカウントに保存** / **未保存の変更** | クラウド・クラウド同期済み・クラウド未同期 | 手元の変更がアカウントの保存先 (PDS) に送られたかどうか |
| 同期 | | 手元とアカウントの間でやり取りすること (「今すぐ同期」はそのまま) |
| PDS | | 説明文の中でだけ使う (ログインの説明など) |

- 「クラウド」を使わないのは、conversensus に中央のサーバが無く、送り先は **その人のアカウント** (PDS) だから。
  状態の表示は「アカウントに保存済み」「未保存の変更 N 件」とする
- #274 ではこの表に従って画面の文言を置き換える

## 8. グラフの描き方

conversensus 固有の部分。ほかのアプリから借りられない。

### 8.1 node

- 枠 1px `--cs-border`、角丸 8px、地 `--cs-bg`、余白 8px 12px、本文 13px (§2)
- **選択**: 枠を `--cs-selection` の 2px にする。**枠の太さが変わっても中身の位置を動かさない** (`outline` か内側の影で描く)
- **接続点は hover か選択のときだけ出す** (#272)。大きさ 8px の丸、地 `--cs-bg`、枠 `--cs-selection`。
  接続をドラッグしている間は、ほかのすべての node の接続点を出す。タッチの端末では選択した node にだけ出す
- **label の chip**: 本文の上に 11px の chip。label が無い node では、**選んだときにも本文の場所を押し下げない** (#272):
  「label を付ける」口は枠の外 (上辺の上) に浮かせて出す
- template の種類で label が固定されている node は、chip を押せない見た目 (枠なし) にする (今のとおり)

### 8.2 edge

- 線 1.5px `--cs-text-muted`、矢印は塗り。選択で `--cs-selection` の 2px
- label は 11px、地 `--cs-bg` の chip (角丸 4px) にのせて線の上に置く。**label どうし・node と重ねない** (#256)。
  重なるときは edge の経路を変えるか、label を線に沿ってずらす

### 8.3 group

- 枠 1px `--cs-border`、地 `--cs-bg-subtle`、上辺に名前の帯 (13px・600)
- 選択は node と同じ (§8.1)。今の常に青い枠はやめる (選択と見分けられないため)
- **ドラッグで group に入れる先**: 枠を `--cs-selection` の 2px にし、地を `--cs-selection-bg` にする
- **group から出す**: 枠を `--cs-text-muted` の破線にする (今は赤。赤は破壊的と競合の色なので使わない)

### 8.4 差分・競合・削除

| 状態 | node | edge |
| --- | --- | --- |
| 追加 | 枠 `--cs-diff-add` 2px・地 `-bg`・右上に `Plus` の印 | 線 `--cs-diff-add` |
| 変更 | 枠 `--cs-diff-update` 2px・地 `-bg`・右上に `Pencil` の印 | 線 `--cs-diff-update` |
| 削除 (ghost) | 不透明度 0.55・破線の枠 `--cs-diff-delete`・本文に打ち消し線 | 線 `--cs-diff-delete` の破線・矢印なし |
| 競合 | 枠 `--cs-conflict` の **破線** 2px | 線 `--cs-conflict` の破線 |

- 差分の印は色に頼らず形でも区別するため (§1.3)
- 差分の枠と選択の枠が重なるときは、差分の枠を残し、選択は外側の輪 (`--cs-focus` と同じ描き方) で示す

### 8.5 キャンバス

- 地は `--cs-bg`、格子の点は `--cs-border-subtle`
- **表示を合わせる** (#257): File を開いたとき・右サイドバーを開閉したとき・metagraph に node を足したときに、グラフ全体が見えるように合わせ直す。
  ただし利用者が自分で動かした後は、開閉で勝手に動かさない (#257 で詰める)

## 9. 空の状態・小さい画面

### 9.1 空の状態 (#279)

空の状態には **何が無いか** と **次に何をすればよいか** を、操作の口と一緒に出す。

| 場面 | 出すもの |
| --- | --- |
| File が 1 つも無い | 「File がありません」+「File を作る」「import」「参加コードで参加する」 |
| Sheet が空 | 「ダブルクリックで node を作る / 右クリックで操作を選ぶ」 |
| 検索の結果が無い | 「『…』に当たるものはありません」 |
| 右サイドバーで何も選んでいない | 「要素を選ぶと、その property が出ます」(今のとおり) |

文字は題 (18px) と本文 (13px・`--cs-text-muted`)。アイコンは 32px の `--cs-text-disabled` を 1 つまで。

### 9.2 小さい画面 (#278)

幅で 3 段に分ける。

| 幅 | 左サイドバー | 右サイドバー | ヘッダ |
| --- | --- | --- | --- |
| 1024px 以上 | 並べて出す | 並べて出す | すべて出す |
| 768〜1023px (iPad の縦) | 並べて出す、既定で畳む | ボディに **重ねて** 出す | すべて出す |
| 767px 以下 (iPhone) | ボディに重ねて出す (外側を押すと閉じる) | 重ねて出す | 記号のボタンだけ、溢れたら `Ellipsis` のメニューに入れる |

- 押せる大きさは **最小 32px 四方** (タッチの端末では 44px)。アイコンが 16px でも押せる範囲は広げる
- 詳細は #278 で、実機 (iPhone・iPad) を見ながら決める
