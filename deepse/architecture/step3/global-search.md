# global search

> [step3](../step3.md) の子文書。出所: Notion「global search」(2026-09-30)。

[step2 の検索](../../requirements/spec/searching.md) は、一つの sheet (グラフ) 内の、しかも
現時点で見えている内容のみを対象とする検索であった。

global search は op-log 全体を対象とする検索である。したがって、通常はさまざまな条件に従って
検索範囲を絞り込むことになる。以下のような検索条件が考えられる。

- File
  - 名前
  - 概要
  - デフォルトは現在の File
- Sheet
  - 名前
  - 概要
  - 適用されている template
  - デフォルトは現在の Sheet
- Node
  - ラベル
  - コンテンツ
  - プロパティの値
  - 種類 (markdown, image など)
- Edge
  - ラベル
  - プロパティの値
- 時間範囲
- Actor
  - ハンドル名
  - デフォルトは参加したことがある人全員
- Branch
  - 名前
  - コメント
- Merge
  - コメント
- (op-log なので、削除したものも含めすべての対象が選択肢となる)

検索結果は、上記の検索条件を満たす op-log の集合である。

通常の検索とは異なり、「Node のコンテンツに "foo" があるか」を検索条件だとすると、
見つかるのは多分、Node の作成や変更時のコンテンツに "foo" が含まれる操作履歴である。
それをユーザにとって有用な形で届けるには、以下のようにする必要がある。

- それらの操作履歴の詳細の一覧を見せ、
- その中から、詳細情報を参考にして、欲しかったものを選択させ、
- その時点でのそのグラフを表示し、
- そのグラフの中で対象 (今の例では node のコンテンツ内の文字列 "foo") を強調表示する

さらに、その周辺を探索するためには、version tree (右サイドバー) も使われるだろう。
